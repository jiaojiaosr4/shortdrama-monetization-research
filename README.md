## 📋 项目简介

2025 年海外短剧市场规模预计 2030 年达 260 亿美元，ReelShort 全年收入超 7 亿美元。本调研用时 2 个月，从**广告埋点逻辑**与**金币经济模型**两个切口，系统拆解海外短剧 App 的变现闭环，回答一个核心问题：

> **"免费但痛苦"的 aggressive freemium 与 "完全免费"的纯广告模式，哪一种才是海外短剧的最优解？**

## 🔬 调研方法论

```
人工体验 + 录屏  →  以真实用户身份走完观看链路，逐广告位记录触发时间戳
      ↓
抓包验证  →  Charles/Fiddler 确认广告 SDK 域名、预加载策略、频控参数（本地 or 服务端）
      ↓
金币逆向  →  记录全部获取入口与消耗场景，推算每日免费上限与单集真实成本
      ↓
公开数据交叉验证  →  Sensor Tower / Insightrackr / 券商研报 / 第三方评测
```

## 💡 核心发现速览

**1️⃣ Aggressive Freemium：免费是付费的催化剂**
ReelShort 每日免费可得 600–700 金币 ≈ 10 集，但一季 60 集需 6–7 天追完；免费金币 8 天过期制造沉没成本焦虑。金币墙的本质是用广告的时间成本倒逼付费——ARPU $19，是 Netflix 移动端的 6 倍。

**2️⃣ 金币获取的"时间-社交-金钱"三角**
看广告（时间成本）+ 关注社媒/下载游戏（社交裂变）+ 充值（金钱），每一类获取渠道同时为平台创造广告收入、用户增长或直接变现——复刻手游经济系统设计。

**3️⃣ 纯 IAA 是规模游戏，不是 ARPU 游戏**
纯 IAA 下载占比一年内从 4.7% 跃升至 24.7%。Melolo 月下载 766 万仅换来 $206 万月收入（RPD <$0.27），收入公式 = DAU × 广告次数 × eCPM，买量效率（CPI < LTV）是生死线。

**4️⃣ 大厂入局正在改写格局**
字节（Melolo）、昆仑万维（FreeReels）、TikTok（PineDrama）相继入局纯 IAA 赛道，用买量能力和内容供应链复制红果模式，金币墙模式的高 ARPU 优势面临"免费无限看"的冲击。
