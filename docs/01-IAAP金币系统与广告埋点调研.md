# 海外短剧 App 广告埋点与金币系统调研报告（IAAP 模式）

> 调研范围：海外主流短剧 App ｜ 重点：广告位埋点逻辑 + 金币经济模型 + 变现闭环
>
> 数据来源：人工体验 / Sensor Tower / 公开行业报告

## 1. 调研背景与目标

2025 年海外短剧市场爆发，ReelShort 全年收入超 7 亿美元，全球短剧市场规模预计 2030 年达 260 亿美元。海外短剧普遍采用 **IAAP 混合变现**（广告 + 内购），核心驱动力是**金币系统**——用户看广告赚金币、充值得金币、消耗金币解锁剧集，形成"内容-货币化-流量"飞轮。

本调研目标：

- **广告埋点分析**：拆解开屏（冷启动/热启动）、插屏、激励视频等广告位的触发逻辑、频次控制、跳过机制
- **金币系统分析**：拆解金币的获取渠道、消耗规则、汇率定价、过期机制
- **商业闭环**：还原广告位与金币系统如何咬合成变现飞轮，对比各 App 的策略差异

## 2. 调研方法

| 方法 | 说明 |
| --- | --- |
| 人工体验 + 录屏 | 下载目标 App，作为真实用户走完完整观看链路，逐广告位录屏记录触发时间戳 |
| 抓包验证 | Charles / Fiddler 抓包，确认广告请求域名（穿山甲/优量汇/Meta Audience Network 等）、请求时机、频控参数 |
| 金币逆向 | 记录所有金币获取入口与消耗场景，推算每日免费获取上限与单集真实成本 |
| 公开数据 | Sensor Tower 收入/下载、点点数据、券商行业报告、第三方评测 |

## 4. 广告埋点分析

### 4.1 广告位类型盘点

海外短剧 App 的广告位通常包含以下类型（不同 App 配置不同）：

| 广告位 | 触发场景 | 核心观察指标 |
| --- | --- | --- |
| 开屏广告（冷启动） | App 首次启动 / 杀进程后重启 | 是否必现、展示时长、可跳过秒数、倒计时样式、素材类型 |
| 开屏广告（热启动） | 从后台切回前台 | 是否触发、冷却间隔、每日频次上限、本地频控 or 服务端下发 |
| 插屏广告 | 剧集切换 / 解锁节点 / 暂停恢复 | 触发节点、是否可立即关闭、频次控制、与金币解锁的衔接 |
| 激励视频 | 主动点击"看广告得金币" / 解锁剧集 | 单次奖励金币数、每日上限次数、视频时长、到账延迟、是否可跳过 |
| 信息流 / Banner | 剧集列表页 / 详情页 | 是否存在、位置、是否影响核心观看体验 |

### 4.2 各广告位触发逻辑（以 ReelShort 为例）

**① 开屏广告 — 冷启动**
App 首次启动或被系统杀死后重启时展示。需观察是否必现（无广告时是否跳过）、展示时长（通常 3–5 秒）、可跳过秒数、是否有品牌广告与效果广告的轮换。

**② 开屏广告 — 热启动**
从后台切回 App 时是否展示开屏。重点记录冷却间隔（如切出 30 秒内再回不触发、超过才触发）和每日上限。此逻辑通常由本地频控或服务端参数控制，抓包可验证。

**③ 插屏广告**
在剧集切换、解锁节点或暂停恢复时弹出。海外短剧的插屏通常可立即关闭（区别于开屏的强制观看），但会打断观看节奏。需记录触发节点与频次。

**④ 激励视频（核心变现位）**
这是 IAAP 模式的命脉——用户主动看广告换金币。以 ReelShort 为例：每日可看 **17–20 次**激励视频，每次奖励 **20 金币**，每日免费获取上限约 **340–400 金币**。广告间隔有 15 秒加载期，单条广告时长 23–60 秒。广告素材多为游戏推广（Temu、Merge World、Chai AI 等），CPG 品牌广告极少。

**抓包验证要点**：用 Charles 抓 HTTPS 请求，关注广告 SDK 域名——穿山甲（pangolin）、优量汇（gdt）、Meta Audience Network、Google AdMob、Unity Ads、AppLovin。通过请求时机确认广告是预加载还是实时拉取，通过返回参数判断频控是本地还是服务端。

## 5. 金币系统分析

### 5.1 金币获取渠道（以 ReelShort 为例，最完整）

ReelShort 的金币获取体系设计极其精细，远超简单的"看广告得币"：

| 获取渠道 | 规则 |
| --- | --- |
| 看激励视频 | 每日 17–20 次，每次 20 金币，上限约 340–400 金币/天，广告间隔 15 秒加载期 |
| 每日签到（7天递增） | Day1-2：10 金币；Day3：80；Day5：20；Day6：30；Day7：200；连续签到有 Streak Bonus |
| 观看时长奖励 | 2分钟 = 12 金币；5分钟 = 18；10分钟 = 30；20分钟 = 80；30分钟 = 100；每日上限 240 金币 |
| 任务矩阵 | 绑定邮箱：30 金币；关注社媒（IG/FB/YT/TikTok）：每个 15 金币；下载关联游戏并通关：30–50 金币；开启推送通知：30 金币 |

**每日免费获取上限测算**：激励视频（~400）+ 观看时长（240）+ 签到（日均~50）+ 任务（一次性）≈ **600–700 金币/天**。按单集 66 金币计，每天可免费看约 9–10 集。一季 60 集需 6–7 天才能免费追完——这就是"aggressive freemium"的节奏控制。

### 5.2 金币消耗规则

| 消耗场景 | 规则 | 说明 |
| --- | --- | --- |
| 解锁单集 | 60–70 金币/集（ReelShort） | 核心消耗口，不同剧集价格浮动 36–111 美分 |
| 免费试看额度 | 前 1–5 集免费 | 不同 App 额度不同，用于建立粘性后开始收费 |
| 金币过期机制 | 免费金币 8 天过期 | 刺激消耗，制造沉没成本心理（ReelShort 独有） |
| VIP 会员（去广告） | 周 $9.99–19.99 / 月 $29.99–39.99 / 年 $99.99 | 会员免广告 + 无限解锁，覆盖高付费意愿用户 |

### 5.3 汇率与定价对比

| App | 基础汇率 | 单集金币 | 单集折价 | 会员方案 |
| --- | --- | --- | --- | --- |
| ReelShort | $9.99 = 1000 金币 | 60–70 | ~¥5 | 周月年 |
| DramaBox | $9.99 = 100 金币 | 5 | ~¥3.5 | 年 $199.99 |
| ShortMax | $9.99 = 1000 金币 | 50 | ~¥3.5 | — |
| FlexTV | $9.99 = 1000 金币 | 65 | ~¥4.5 | 周 $29.99 |
| GoodShort | $9.99 = 1000 金币 | 50 | ~¥3.8 | — |

**关键算账**：ReelShort 单集约 $0.6–0.7，一季 60 集需 ~$40——比 Netflix 月费还贵。但用户可选择看广告免费解锁（每天 ~10 集），6–7 天追完一季。这就是 IAAP 的精髓：**用广告的时间成本倒逼付费**。

## 6. 商业闭环模型

海外短剧的核心商业逻辑是 **广告位 × 金币系统 = 变现飞轮**：

```
开屏广告(冷/热启动) → 插屏广告(剧集切换) → 激励视频(看广告得金币) → 金币解锁(看下一集)
        ↑ ______________________ 解锁后继续看剧 → 再次触发插屏/激励视频循环 _____________________↓
```

飞轮的三层逻辑：

1. **打断式广告**（开屏/插屏）赚取基础曝光，覆盖所有用户，贡献 IAA 收入
2. **激励视频**把广告变成"用户主动求着看"的资源，喂给金币系统
3. **金币墙**用"免费但痛苦"的节奏控制，把高时间价值用户倒逼为付费用户，贡献 IAP 收入

**ReelShort 数据印证**：2025年3月 ARPU 达 19 美元，是 Netflix 移动端 ARPU 的 6 倍。全年收入超 7 亿美元，累计下载 3.7 亿次。高 ARPU 反向支撑 12–14 美元/新增的激进买量成本，形成"高 ARPU → 高买量预算 → 榜单上升 → 自然流量 → 更多用户"的自循环。

## 7. 关键洞察

**洞察一：Aggressive Freemium 是核心策略**
免费不是福利，而是付费的催化剂。金币系统被设计得"够用但永远不够"——每天免费看 10 集，一季要追一周。金币过期机制（8天）制造沉没成本焦虑。47.8% 的 ReelShort 差评抱怨价格贵，但这恰恰证明策略在筛选付费用户。

**洞察二：金币获取渠道的"时间-社交-金钱"三角**
ReelShort 的金币获取设计复刻了手游：看广告（时间）+ 关注社媒/下载游戏（社交裂变）+ 充值（金钱）。每一类渠道都在为平台创造额外价值——广告收入、用户增长、直接变现。

**洞察三：广告素材以效果广告为主**
海外短剧的广告填充多为游戏推广（Temu、小游戏、AI 聊天），CPG 品牌广告极少。说明广告主以效果导向为主，eCPM 依赖下载转化，品牌广告主尚未大规模入场——这也意味着广告收入天花板受限于效果广告市场容量。

**洞察四：纯 IAA 的威胁正在出现**
字节跳动 Melolo 等纯 IAA 免费平台正在挤压付费空间。如果纯广告模式能跑通（依赖高 DAV + 高填充），金币墙模式的高 ARPU 优势可能被"免费无限看"冲击。
