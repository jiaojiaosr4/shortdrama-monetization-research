# 海外纯 IAA 短剧 App 广告埋点调研报告

> 调研范围：海外纯广告变现短剧 App（无内购/无金币墙）｜ 重点：广告位埋点逻辑 + 广告密度 + 变现机制
>
> 数据来源：Sensor Tower / Insightrackr / 人工体验

## 1. 调研背景与目标

2025 年海外短剧市场出现显著结构性变化：纯 IAA（广告变现）短剧应用下载量占比从 2024 年的 4.7% 跃升至 24.7%，增长超 20 个百分点。字节跳动 Melolo、昆仑万维 FreeReels 等免费短剧产品快速崛起，TikTok 也在 2026 年推出 PineDrama 加码 IAA 赛道。

与 ReelShort/DramaBox 等 IAAP 混合变现产品不同，纯 IAA 短剧的核心特征是：完全免费、无内购、无金币墙，用户看广告换取观看时长或解锁剧集，平台收入 100% 来自广告。这类产品主要集中在东南亚、南美等价格敏感市场。

本调研目标：

- **广告埋点分析**：拆解纯 IAA 短剧的开屏（冷/热启动）、插屏、激励视频、信息流等广告位的触发逻辑与频次控制
- **变现机制分析**：分析"看广告换时长/解锁"的变现机制，对比各 App 的广告密度策略
- **商业模型**：还原纯广告变现飞轮，对比 IAAP 模式的差异

## 2. 调研方法

| 方法 | 说明 |
| --- | --- |
| 人工体验 + 录屏 | 下载目标 App，完整观看 30 分钟以上，逐广告位录屏记录触发时间戳，测算广告密度（次/小时） |
| 抓包验证 | Charles / Fiddler 抓包，确认广告请求域名、预加载逻辑、频控参数 |
| 广告密度测算 | 记录单位时间内的广告展示次数，区分开屏/插屏/激励视频的占比 |
| 公开数据 | Sensor Tower、Insightrackr 收入/下载/买量数据、行业报告 |

## 4. 广告埋点分析

### 4.1 广告位类型盘点

纯 IAA 短剧的广告位与 IAAP 有重叠，但权重不同——纯 IAA 的广告密度更高，激励视频不再是"换金币"而是"换时长/解锁"：

| 广告位 | 触发场景 | 核心观察指标 | 与 IAAP 的差异 |
| --- | --- | --- | --- |
| 开屏广告（冷启动） | App 首次启动 / 重启 | 是否必现、时长、可跳过秒数 | 基本一致 |
| 开屏广告（热启动） | 从后台切回前台 | 冷却间隔、每日频次 | 纯 IAA 可能更激进（无付费用户保护） |
| 插屏广告 | 剧集切换/解锁节点 | 触发节点、频次、可关闭性 | 密度更高，是主要变现位 |
| 激励视频 | 主动看广告换时长/解锁 | 单次奖励时长、每日上限、视频时长 | 奖励是"观看时长"而非"金币" |
| 信息流/Banner | 剧集列表/详情页 | 位置、密度、原生广告融合度 | 纯 IAA 更依赖信息流填充 |
| **广告密度（关键）** | 单位时间广告展示次数 | 次/小时、广告占比时长 | 纯 IAA 独有核心指标 |

### 4.2 各广告位触发逻辑（以 Melolo 为例）

**开屏广告 — 冷启动**：App 首次启动时展示。Melolo 作为纯免费产品，开屏广告是基础曝光位。需观察是否每次冷启动必现、展示时长、可跳过秒数。

**开屏广告 — 热启动**：从后台切回是否触发开屏。纯 IAA 产品可能对热启动开屏更激进（因为所有用户都是免费用户，无需保护付费体验）。重点记录冷却间隔与每日上限。

**插屏广告（主要变现位）**：纯 IAA 模式下，插屏广告是收入主力——在剧集切换、解锁节点高频弹出。Melolo 的机制是"看广告获取观看时长"，插屏可能出现在每集切换或每 N 集切换时。需精确记录触发节点和频次。

**激励视频（换时长/解锁）**：纯 IAA 的激励视频奖励不是金币，而是"观看时长"或"解锁集数"。例如看一条 30 秒广告可继续观看 30 分钟，或解锁下一集。这是纯 IAA 的核心变现逻辑。

**信息流 / 原生广告**：在剧集列表页、详情页融入的原生广告。纯 IAA 产品更依赖信息流填充来提升广告展示量。

**广告密度是纯 IAA 的命门**：纯广告变现的 ARPU 极低（RPD < $0.2），必须靠高 DAU × 高广告密度堆出收入。核心对比指标是"连续观看 30 分钟内触发的广告总次数"换算成次/小时。

## 5. 广告变现机制分析

### 5.1 变现机制类型

| 机制类型 | 说明 | 代表产品 | 广告负载 |
| --- | --- | --- | --- |
| 看广告换时长 | 看 1 条广告换取 N 分钟观看时长，时长耗尽需再看广告 | Melolo | 中高 |
| 看广告解锁集数 | 每集/每 N 集需看 1 条广告解锁 | 待确认 | 高 |
| 去广告特权（留存激励） | 累积观看指定数量视频或参与活动，解锁去广告特权 | Melolo | 递减 |
| 纯插屏打断 | 无主动激励，靠插屏高频打断变现 | 待确认 | 最高 |

### 5.2 Melolo 变现机制详解

Melolo 的变现设计复刻了红果短剧的"免费+广告"模式，核心是让广告成为用户主动接受的"门票"：

- **看广告换时长**：用户观看广告获取对应观看时长（非金币，是时间货币）
- **去广告特权**：累积观看指定数量视频或参与活动，可获得去广告特权（刺激留存）
- **插屏打断**：剧集切换时插入插屏广告，是基础曝光收入
- **信息流填充**：在列表页、详情页融入原生广告，提升填充率

## 6. 商业闭环模型

纯 IAA 短剧的变现飞轮与 IAAP 截然不同——没有金币墙倒逼付费，完全靠广告密度和用户规模：

```
免费内容(全部剧集免费) → 广告打断(开屏/插屏高频) → 看广告换时长 → 继续观看(留存+去广告特权)
        ↑ __________________ 继续观看 → 再次触发广告打断 → 靠 DAU 规模 × 广告密度堆收入 ___________________↓
```

飞轮的三层逻辑：

1. **免费内容**降低门槛，快速获取海量用户（Melolo 月下载 760万+）
2. **高广告密度**变现，靠 DAU × 广告次数 × eCPM 堆出收入
3. **去广告特权**作为留存钩子，让重度用户留下并贡献更高活跃度

与 IAAP 的本质差异：IAAP（ReelShort）用"免费但痛苦"倒逼付费，ARPU 高（$19）但 DAU 小；纯 IAA（Melolo）完全免费，ARPU 极低（RPD<$0.2）但 DAU 大。纯 IAA 的收入 = DAU × 人均广告展示 × eCPM，规模是唯一杠杆。

## 7. 关键洞察

**洞察一：纯 IAA 是"规模游戏"，不是"ARPU 游戏"**
纯 IAA 短剧的 RPD 低于 $0.2，远低于 IAAP 产品。收入完全依赖 DAU 规模和广告密度。Melolo 靠月 760 万下载堆出 $206 万月收入，本质是"薄利多销"。这意味着买量效率（CPI < LTV）是生死线。

**洞察二：广告密度是产品设计的核心矛盾**
广告越多收入越高，但用户流失也越快。纯 IAA 必须在"广告密度"和"留存率"之间找平衡点。Melolo 用"去广告特权"作为留存钩子——让重度用户通过活跃度换取免广告，既留住高价值用户又不让其付费流失（因为本来就没有付费入口）。

**洞察三：东南亚是纯 IAA 的主战场**
纯 IAA 集中在印尼、菲律宾、巴西等价格敏感市场，用户付费意愿低但广告接受度高。欧美市场仍以 IAAP 为主。Melolo 在美国占 18% 下载，但美国用户 ARPU 更高，未来可能在美国市场加入 IAP 转混合变现。

**洞察四：大厂入局加速 IAA 赛道竞争**
字节（Melolo）、昆仑万维（FreeReels）、TikTok（PineDrama）相继入局，IAA 短剧下载占比从 4.7% 暴涨到 24.7%。大厂凭借买量能力和内容供应链优势，可能复制红果在国内的成功——用规模碾压中小玩家。AI 短剧进一步降低内容成本，使"高频供给+广告变现"的规模化路径可持续。

## 8. 附录

### 8.1 IAA vs IAAP 模式对比

| 维度 | 纯 IAA（Melolo） | IAAP（ReelShort） |
| --- | --- | --- |
| 付费门槛 | 无，完全免费 | 有金币墙，需付费或看广告解锁 |
| ARPU/RPD | RPD < $0.2 | ARPU $19 |
| DAU 规模 | 大（月下载760万+） | 小但付费率高 |
| 广告密度 | 高（核心收入来源） | 中（辅助收入） |
| 核心市场 | 东南亚/南美 | 欧美 |
| 收入公式 | DAU × 广告次数 × eCPM | 付费用户数 × ARPPU + 广告 |
| 风险 | 买量成本 > LTV 则亏损 | 内容同质化 + 盗版 |

### 8.2 广告密度测算方法

1. 连续观看 30 分钟，记录期间所有广告展示（开屏/插屏/激励/信息流）的次数和时间戳
2. 换算成"次/小时"，并拆分各广告位占比
3. 记录"广告总时长/观看总时长"的比例（广告占比时长）
4. 对比 4 款 App 的广告密度，分析密度与评分的关系（密度过高是否导致差评）

### 8.3 抓包工具配置

- **Charles**：开启 SSL Proxying，手机配置代理，安装根证书并信任
- **iOS**：设置 → 通用 → 关于本机 → 证书信任设置 → 开启 Charles 证书
- **Android**：部分 App 有 SSL Pinning，需用 Frida 或 HttpCanary 绕过
- **关注域名**：pangolin（穿山甲/Pangle）、gdt（优量汇）、admob（Google）、audience network（Meta）、applovin、unityads
- 记录每次广告请求时间戳，与录屏对齐，验证触发逻辑和预加载策略
